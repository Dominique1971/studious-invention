ASSETS DIRECTORY
================

Kenney.nl packs (CC0):
  Download manually from https://kenney.nl and place ZIP files under
  assets/_cache/ with the names listed in asset_downloader.py.

AmbientCG textures (CC0):
  Downloaded automatically when internet is available.

Audio:
  Place .ogg / .wav files under assets/audio/
  The engine generates procedural audio if files are missing.
